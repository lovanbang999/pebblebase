---

SQLite không đòi hỏi tiến trình máy chủ cơ sở dữ liệu nào. Bạn chỉ cần trỏ Pebblebase Studio tới bất kỳ file `.db`, `.sqlite` hoặc `.sqlite3` nào trên máy tính.

---

## Khả năng Hỗ trợ

- **Driver Nhúng Hiệu năng cao**: Tích hợp sẵn engine SQLite tốc độ cao viết bằng Go.
- **Tương thích Chế độ WAL**: Hoạt động an toàn và ổn định với các cơ sở dữ liệu bật Write-Ahead Logging (WAL).
- **Chọn file trực quan**: Nhấp vào biểu tượng chọn file trong hộp thoại kết nối để duyệt và mở file cơ sở dữ liệu nhanh chóng.
