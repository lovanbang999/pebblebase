title: Phím tắt Bàn phím (Shortcuts)
description: Bảng tra cứu phím tắt đầy đủ giúp thao tác nhanh trong Pebblebase Studio.
---

Pebblebase Studio được thiết kế ưu tiên bàn phím (keyboard-first) để tối đa hóa tốc độ làm việc của lập trình viên.

---

## Phím tắt Toàn cục

| Thao tác | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **Command Palette** | `Cmd + K` | `Ctrl + K` |
| **Bật/Tắt Query Console** | `Option + Q` | `Alt + Q` |
| **Bật/Tắt Sơ đồ ERD** | `Option + E` | `Alt + E` |
| **Bật/Tắt Thanh Sidebar** | `Cmd + B` | `Ctrl + B` |
| **Thực thi Truy vấn** | `Cmd + Enter` | `Ctrl + Enter` (hoặc `F5`) |
| **Tìm kiếm / Lọc Bảng** | `Cmd + F` | `Ctrl + F` |
| **Toàn màn hình** | `F11` | `F11` |
| **Thoát ứng dụng** | `Cmd + Q` | `Ctrl + Q` |
