---
title: Query Console
description: Full-featured SQL and NoSQL query console with syntax highlighting, autocomplete, and query history.
---

Press `Alt+Q` (or `Option+Q` on macOS) from anywhere in Pebblebase Studio to toggle the **Query Console**.

---

## Capabilities

- **CodeMirror 6 Editor**: Modern, lightweight editor with SQL syntax highlighting, auto-indentation, and bracket matching.
- **Keyboard Execution**:
  - Run Query: `Ctrl+Enter` (Windows/Linux) or `Cmd+Enter` (macOS).
  - Alternative: `F5`.
- **Query History**: Automatically preserves your past queries with execution timestamps and execution times (ms).
- **Saved Queries**: Save frequently used queries, tag them, and access them rapidly via the Command Palette (`Ctrl+K`).
- **Multiple Result Tabs**: Run complex batch queries and inspect result sets in dedicated tabs without overriding previous data.
