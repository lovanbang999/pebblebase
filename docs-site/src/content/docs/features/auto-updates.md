---
title: One-Click Auto Updates
description: How Pebblebase Studio discovers, downloads, and applies in-app desktop updates.
---

Pebblebase Studio features a built-in auto-update system that connects directly to official GitHub Releases.

---

## Update Discovery

- **Automatic Startup Checks**: When enabled in settings, Pebblebase Studio checks for newer versions on startup in the background.
- **Manual Triggers**:
  - Click the version badge in the desktop title bar.
  - Click the version pill at the bottom of the left sidebar.
  - Open the **User Profile Menu** (bottom-left) and select **"Check for Updates..."**.
  - Open the **Command Palette** (`Ctrl+K`) and search for **"Check for Software Updates"**.

---

## Update Process

1. When an update is ready, a notification banner and dialog appear displaying the new release version and release notes.
2. Clicking **"Update Now"** downloads the official archive in the background and verifies integrity.
3. Once downloaded, click **"Restart Pebblebase Studio Now"** to launch the new version without losing your saved connections or queries.
