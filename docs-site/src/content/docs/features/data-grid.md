The Pebblebase Studio Data Grid is engineered for large datasets, using virtualized DOM rendering to smoothly handle millions of records without browser lag.

---

## Key Features

- **Virtualized Scrolling**: Only visible rows are rendered in the DOM, keeping scrolling silky smooth at 60fps.
- **Inline Editing**: Double-click any cell to edit the value. Changes are validated against the column schema before executing the SQL `UPDATE`.
- **Column Filters & Search**: Click the search icon on any column header or press `Ctrl+F` to search by substring, exact match, or range.
- **Sorting**: Click any column header to toggle ascending, descending, or default sorting.
- **Exporting Data**: Export current table views directly to **CSV** or **JSON** format with a single click or via `Ctrl+K`.
- **Foreign Key Navigation**: Click on foreign key badges to jump directly to the referenced record in the foreign table.
