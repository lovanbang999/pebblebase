---

## Global Shortcuts

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **Command Palette** | `Cmd + K` | `Ctrl + K` |
| **Toggle Query Console** | `Option + Q` | `Alt + Q` |
| **Toggle ERD Diagram** | `Option + E` | `Alt + E` |
| **Toggle Sidebar** | `Cmd + B` | `Ctrl + B` |
| **Execute Query** | `Cmd + Enter` | `Ctrl + Enter` (or `F5`) |
| **Filter Columns** | `Cmd + F` | `Ctrl + F` |
| **Toggle Fullscreen** | `F11` | `F11` |
| **Quit App** | `Cmd + Q` | `Ctrl + Q` |
