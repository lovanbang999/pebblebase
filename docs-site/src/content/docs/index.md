## Core Highlights

### 🗄️ Multi-Database Engine Support
Seamlessly connect to **PostgreSQL**, **MySQL**, **MariaDB**, **SQLite**, and **MongoDB** using a unified, responsive interface with instant schema introspection.

### 📊 Visual Interactive ERD
Explore complex entity relationships visually with auto-layout DAG diagrams, foreign-key tracing, table zoom/pan, and one-click query generation.

### 🔄 Schema Diff & Sync
Compare structural differences across local, staging, and production databases with visual color-coded DDL comparison and migration generator.

### ⚡ Native Desktop Speeds
Built with **Go** and **Wails v2** for instant startup and minimal RAM footprint. Complete privacy—all credentials and queries stay strictly on your local machine.

### 🚀 1-Click Background Updates
Never miss bug fixes or new features. Built-in silent background updater with zero-friction in-app updates and automatic binary restart.

### 🐳 Docker Self-Hosting
Deploy anywhere as a private, secure web studio container with multi-user authentication, role-based access control, and zero configuration.
