---
title: SQLite
description: Open, inspect, and modify local SQLite database files with zero setup.
---

SQLite requires no database server process. Simply point Pebblebase Studio to any `.db`, `.sqlite`, or `.sqlite3` file on your filesystem.

---

## Capabilities

- **Embedded Drivers**: Uses Go's high-speed CGO/pure-Go SQLite engine.
- **WAL Mode Compatibility**: Works safely with Write-Ahead Logging (WAL) databases.
- **Direct File Selection**: Click the file picker icon in the connection dialog to browse and select files easily.
